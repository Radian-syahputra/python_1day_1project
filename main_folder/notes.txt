--- Literal | Literal adalah nilai yang tidak berubah
--- Literal | Contoh: 1, 2.5, "Hello", True, False

--- Tipe Data Dalam Literal | Tipe data dalam literal adalah tipe data yang digunakan untuk merepresentasikan nilai yang tidak berubah
--- Tipe Data Dalam Literal | Contoh: int, float, str, bool

-- int | int adalah tipe data yang digunakan untuk merepresentasikan bilangan bulat, seperti -1, 0, 1

-- float | float adalah tipe data yang digunakan untuk merepresentasikan bilangan desimal, seperti -1.5, 0.0, 1.2

-- str | str adalah tipe data yang digunakan untuk merepresentasikan string, seperti "Hello", "World"

-- bool | bool adalah tipe data yang digunakan untuk merepresentasikan nilai boolean, seperti True, False
